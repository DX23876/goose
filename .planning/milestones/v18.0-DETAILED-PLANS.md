New domain needs (a) new guard arm, (b) new `bridge/<domain>.rs` module, (c) method strings registered **alphabetically** in the `BRIDGE_METHODS` constant, (d) a dispatch match arm. Test `bridge_methods_constant_matches_dispatcher` enforces (c)+(d) parity — it will fail if you forget.
- **Profile already has** `OnboardingStorage.dateOfBirth` and `OnboardingStorage.gender` (`MoreProfileViews.swift:91,97`). Age derivation exists: `HealthDataStore.profileAgeYears(from:)`. **Do not add a new age/sex field** — reuse these.

- **`HealthKitFullImporter`** already reads RHR, HRV-SDNN, respiratory rate, SpO2, skin temp, steps, active kcal, HR samples, workouts + 90-day HRV/RHR history (`hrvHistory`, `rhrHistory`).
- **`NotificationScheduler` actor** (`NotificationScheduler.swift:5`) has a private `schedule(title:body:identifier:)` and public `scheduleSleepProcessed`/`scheduleWorkoutDetected`/`scheduleBatteryLow`. Add briefing scheduling here.
- **In-flight uncommitted work** (working tree, 6 files) already adds `HealthKitSleepImporter.importSleep(forDate:)` + `HealthKitSleepHistoryImporter` (bulk, idempotent) + a body-composition section + sleep calendar nav. **This must be committed as Phase 152 Task 1 before anything stacks on it.**
- **Coach:** `CoachLocalToolContext.build()` assembles a `tools` dict of metric rows; `HealthDataStore+CoachSummaries.swift` holds the per-metric summary strings. Extend both, no provider-specific code.
- **SDNN ≠ RMSSD guard:** `healthkit_rmssd_must_not_be_written_as_sdnn`. Apple Health HRV is SDNN; Goose/WHOOP compute RMSSD. Never cross them.

## Phase 156 — Bio Age Engine (Rust core) — ALGORITHM SPEC

**Wave 2, depends on 151.** Requirements: BIO-01, BIO-02, BIO-03. **This is the one phase to design/review with a strong model.** The spec below is deliberately explicit so no reference values are invented at implementation time.

### Model

`BioAge = chronological_age + Σ (factor_offset_years × factor_weight)`, then clamp to `[chronological_age − 20, chronological_age + 20]`.

Each factor maps the user's value to a percentile within their **age×sex** population norm, then to a year-offset: better-than-median → negative offset (younger), worse → positive. Offset magnitude is bounded per factor (e.g. ±8y before weighting) so no single factor dominates.

### Factors, weights, and norm sources (cite in code comments)

| Factor | Input | Weight | Norm source to cite |
|---|---|---|---|
| VO2max | `apple_daily.vo2max` (Watch) | 0.30 | Cooper Institute / ACSM VO2max percentiles by age & sex |
| HRV | RMSSD when WHOOP-sourced; SDNN when Health-sourced — **separate norm tables, never mixed** | 0.25 | Published age-stratified HRV norms (e.g. Umetani 1998 for SDNN; Nunan 2010 meta for RMSSD) |
| RHR | resting HR bpm | 0.20 | Age/sex resting HR norms (e.g. AHA / population percentiles) |
| Sleep | duration + consistency + efficiency composite | 0.15 | Age-based sleep-need norms (NSF recommendations) |
| Activity | steps + active kcal + weekly workout frequency | 0.10 | Physical-activity guideline thresholds (WHO 150min/wk equivalent) |

Weights sum to 1.0. **Which HRV norm table is used depends on the value's `source` field from Phase 151** — this is where the SDNN≠RMSSD guard lives at the algorithm level.

### Inputs & degradation

- Chronological age from `OnboardingStorage.dateOfBirth` (present), sex from `OnboardingStorage.gender` (present) — optionally prefill sex from HealthKit `HKCharacteristicType` biologicalSex if profile empty.
- **Missing factor degrades gracefully:** if VO2max or sex is absent, that factor drops out, remaining weights renormalise, and confidence lowers. Never substitute a fake value.

### Confidence tiers

`Calibrating` (<7 days data for the factor set) / `Building` (7–29) / `Solid` (≥30). Align wording with upstream Phase 140 EWMA tiers **but do not hard-depend on Phase 140 shipping** — this fork may not have it.

### Tasks

1. (TDD RED) `Rust/core/tests/bio_age_tests.rs`: fixtures per factor (each factor's value at p10/p50/p90 → expected offset sign & bounded magnitude), norm-table boundary cases, missing-VO2max degradation (factor drops, weights renormalise), missing-sex degradation, clamp at ±20y.
2. Norm tables as `const` arrays with source citation comments; percentile-lookup helper (linear interp between bracket points).
3. `metrics.bio_age` bridge method: computes per-factor offsets + weighted BioAge + confidence tier; returns per-factor breakdown (value, percentile, offset_years) for the UI.
4. Persist daily BioAge snapshot to SQLite (new `bio_age_snapshots` table, migration step 26 if 151 took 25) for trend rendering.
5. `cargo test --locked` green; fmt; clippy clean.

**Exit:** deterministic BioAge on the synthetic fixture; missing-input paths never fabricate; every norm value has a cited source in-code.
